# DrewBuilds Portfolio Website

This is my personal portfolio website created to showcase my projects, technical skills, education, values, and growth as a developer.


## Overview

DrewBuilds.com is a personal developer portfolio designed to present my background, software development projects, technical abilities, education, and professional values in one clean and organized place.

The website serves as a digital resume and personal brand site for employers, clients, and collaborators who want to learn more about my work.

## Tech Stack

* HTML
* CSS
* JavaScript

## Main Sections

### Projects

Highlights the software and web development projects I have built, including personal applications and client websites.

### Skills

Displays the programming languages, tools, platforms, and technical concepts I have experience with.

### Ethics

Shares the values and work ethic that guide how I approach development, teamwork, leadership, and problem solving.

### Education

Provides information about my academic background and studies in Computer Information Systems and Business Administration.

### Contact

Gives visitors a way to connect with me for job opportunities, project work, or professional collaboration.

## Features

* Responsive portfolio layout
* Dark-themed visual design
* Custom branding and logo
* Smooth navigation between sections
* Project showcase area
* Skills and education sections
* Contact section for professional outreach
* Clean and simple user experience

## Purpose

The purpose of this portfolio is to create a professional online presence that clearly presents who I am, what I have built, and what I am continuing to learn as a developer.

This site helps organize my work into one place so recruiters, employers, clients, and collaborators can quickly view my background and projects.
